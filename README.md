## 📥 下载安装

1. 前往 [Releases](https://github.com/zouzuo1994321) 页面下载最新的 `摸鱼文书.exe`（单文件，约 277 MB）。
2. 双击运行即可，无需安装 —— 本机需已安装 **WPS Office**（个人版/专业版均可）。
3. 全程离线，不依赖网络与浏览器。

## 🚀 快速上手

1. 双击 `摸鱼文书.exe` 启动。
2. 点「导入文档」，选择 Word / TXT / PDF 文件，面板自动解析字数并生成目录。
3. 点「开始摸鱼」—— 软件拉起真实 WPS 打开空白文档。
4. 切到 WPS 窗口，**按任意键**即逐字“打”入文章：
   - **关闭输入法**（英文态）= 按键摸鱼，按一下出一个字；
   - **打开输入法**（中文态）= 随时手动打字 / 修改；
   - 退格 / Delete / 方向键 / Home / End 真实生效，可删字、移动光标。
5. `F9` 暂停 / 继续；`Alt+Tab` 切回控制面板；`Ctrl+S` 在 WPS 里保存。

> 可选：在面板里配置「假弹窗广告」，摸鱼气氛直接拉满 😎

## ❓ 常见问题 FAQ

**Q: 为什么字打不进 WPS？**  
确认 WPS 处于前台且输入法处于关闭状态（按键摸鱼模式）。输入法开着时软件会放行按键让你手动打字，不会“自动出字”。

**Q: 弹窗广告的网页打不开视频 / 提示“不支持 HTML5 播放器”？**  
内嵌浏览器（QtWebEngine）不含 **H.264/AAC 专有编解码器**（开源协议限制），网页里的 MP4 视频无法直接播放。两个解决方式：

- 广告 URL 直接填**视频文件直链**（`.mp4` / `.webm` 结尾）→ 自动改用本地播放器播放（支持 H.264）；
- 点弹窗左下角「🌐 系统浏览器打开」→ 用真实浏览器观看视频网站。

**Q: 弹窗会打断我打字吗？**  
默认广告图模式不抢 WPS 焦点、不影响打字；网页/视频模式需要交互，点击弹窗会切走前台，关闭弹窗回 WPS 即继续。

**Q: 支持哪些系统？**  
Windows 10/11（64 位），需已安装 WPS Office。

## 📁 项目结构

```
摸鱼软件/
├── main.py               # 程序入口
├── moyuapp/              # 源码包
│   ├── controller.py     # 控制面板 + 系统托盘（主控）
│   ├── wps_driver.py     # 真 WPS 驱动器（拉起/聚焦/WM_CHAR 逐字输入/IME）
│   ├── keyboard_hook.py  # 全局低级键盘钩子
│   ├── docimport.py      # 文档导入与结构识别（离线引擎）
│   ├── gongwen.py        # GB/T 9704-2012 公文排版模板
│   ├── ad_popup.py       # 假右下角弹窗广告（图/网页/视频）
│   ├── process_guard.py  # 进程守护（启动清理/退出强杀）
│   └── themes.py         # 黑 / 白皮肤 QSS
├── assets/               # 图标与内置广告图
├── fonts/                # 打包字体（开源回退字体）
├── samples/              # 示例文档
├── tests/smoke.py        # 离屏冒烟测试（84 项）
├── history/              # 近两版 exe 留档
├── 摸鱼文书.spec          # PyInstaller 打包配置
└── 摸鱼文书.exe           # 最新版 exe
```
